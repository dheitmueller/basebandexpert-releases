# BasebandExpert Analyzer v1.4

This release provides a signed and notarized Apple-silicon installer for
BasebandExpert Analyzer.

## Highlights

- **DekTec DTU-351 capture** — support for DekTec DTU-351 on macOS.
- **SDI and HDMI connectors** — supported DeckLink devices expose explicit SDI
  or HDMI input-connector selection.
- **Persistent input selection** — each Analyzer session restores its previous
  device choice after restart when that device remains available.
- **Input stability evidence** — improved display of unstable HDMI signal
  sources, with visible warning and recovery events.
- **Native capture fixes** — the pinned receiver stack includes current preview
  cadence and SMPTE ST 299 ancillary-data corrections.

## Requirements

- Apple silicon
- macOS 14 or newer
- For Blackmagic SDI capture, Blackmagic Desktop Video 16.0 or newer
- For direct DekTec capture, a DTU-351 connected by USB 3.0

## Corresponding source

The Analyzer FFmpeg source-and-build archive contains the FFmpeg 8.0 source,
release configuration, license material, and libopus license corresponding to
the libraries distributed in the application.
