# BasebandExpert v1.2

This release provides signed and notarized Apple-silicon installers for
BasebandExpert Generator and BasebandExpert Analyzer.

## Included applications

- **BasebandExpert Generator v1.2** — adds the hardware-free Virtual Output and
  NDI video/audio/ancillary-data output alongside DeckLink output.
- **BasebandExpert Analyzer v1.2** — adds the hardware-free virtual input and
  NDI source discovery and analysis alongside DeckLink input.

The Analyzer installer intentionally excludes the experimental DTU-351
user-space driver, firmware, receiver executable, and GUI device entry.

## Requirements

- Apple silicon
- macOS 26 or newer
- Blackmagic Desktop Video only when DeckLink hardware is used

Both disk images are signed with a Developer ID Application certificate,
notarized by Apple, and contain a stapled notarization ticket.

`FFmpeg-8.0-LGPL-source-and-build.zip` contains the corresponding source and
build material for the dynamically linked LGPL FFmpeg libraries shipped with
BasebandExpert Generator and used by the Analyzer virtual input.
