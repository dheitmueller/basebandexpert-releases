# BasebandExpert v1.3

This release provides signed and notarized Apple-silicon installers for
BasebandExpert Generator and BasebandExpert Analyzer.

## Highlights

- **Offline perpetual licensing** — both products now accept signed
  `.belicense` files, display the installed license in About, and provide a
  full-featured 15-minute trial before licensed operation is required.
- **Generator** — expands release qualification and reports unsupported MCC
  caption output rates before playout.
- **Analyzer** — adds persistent fault history, configurable measurement
  alarms, pre-trigger evidence bundles, and selectable low-latency live
  preview with automatic hardware acceleration.
- **Release integrity** — both applications and both disk images are signed,
  independently notarized, stapled, and verified with Gatekeeper. Release
  builds use checksum-pinned SDKs, source revisions, Node.js, pnpm, and
  product-specific FFmpeg configurations.

## Requirements

- Apple silicon
- macOS 26 or newer
- Blackmagic Desktop Video when DeckLink hardware is used

## Corresponding source

The Generator and Analyzer use different LGPL FFmpeg configurations. Their
separate source-and-build archives contain FFmpeg 8.0 source, configuration,
license material, and the additional libopus license used by Analyzer.
