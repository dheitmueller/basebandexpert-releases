# BasebandExpert v1.1

This release provides Apple-silicon installers for the BasebandExpert Generator,
Analyzer, and Router products.

## Included applications

- **BasebandExpert Generator v1.1** — test-pattern and file playout with video,
  multichannel PCM audio, captions, VANC, HDR metadata, and DeckLink output.
- **BasebandExpert Analyzer v1.1** — live picture, scopes, audio, HDR, A/V sync,
  caption, VANC, and device inspection.
- **BasebandExpert Router v1.1** — NMOS and baseband router discovery,
  inspection, and control.

Demo builds display a Demo mode indicator. Generator additionally burns the demo
identification into its video output. Each application ends its demo session
after 15 minutes and displays a thank-you message before closing.

## Requirements

- Apple silicon
- macOS 26 or newer
- Blackmagic Desktop Video for Generator and Analyzer hardware access

All three disk images are signed with a Developer ID Application certificate,
notarized by Apple, and contain the standard drag-to-Applications installer
layout.

`FFmpeg-8.0-LGPL-source-and-build.zip` contains the corresponding source and
build material for the dynamically linked LGPL FFmpeg libraries shipped with
BasebandExpert Generator.
