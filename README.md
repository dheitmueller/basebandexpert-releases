# BasebandExpert releases

This repository publishes signed and notarized macOS installers for the
[BasebandExpert](https://www.basebandexpert.com) product family. Product source
code is maintained separately in private repositories; this repository contains
release metadata and public binary downloads only.

## Products

- **BasebandExpert Generator** — professional video, audio, and ancillary-data
  signal generation and file playout.
- **BasebandExpert Analyzer** — live baseband signal analysis, scopes, audio
  monitoring, and ancillary-data inspection.
- **BasebandExpert Router** — NMOS and baseband routing discovery, inspection,
  and control.

## System requirements

- Apple silicon
- macOS 26 or newer
- Blackmagic Desktop Video for Generator and Analyzer hardware access

Each disk image is signed with a Developer ID certificate and notarized by
Apple. Published SHA-256 checksums are available in the release notes and in
the `checksums` directory.
